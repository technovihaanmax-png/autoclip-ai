# AUTOCLIP AI

An Apple-inspired, responsive first interface for an automatic vertical video clipping studio.

## Current preview
- Welcome screen with YouTube URL validation
- Three selectable vertical gameplay / facecam layouts
- Caption-style selection
- Creator-name field
- Review screen showing the selected setup
- Responsive desktop and mobile layout

## Important
This is the first frontend prototype. It does **not** download YouTube videos or process video yet. The next stages are to connect a permitted video source, build the video-processing backend, detect highlights and facecam, generate Hinglish captions, add smart zoom/reframing, and export vertical clips.

## Run locally
Open `index.html` in a browser, or publish the repository with GitHub Pages.

## Files
- `index.html` — page structure
- `style.css` — visual design and responsive styles
- `script.js` — navigation and selections
